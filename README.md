# Number Guessing Game

A simple command-line number guessing game built in Python as my first project.

## How it works

- The computer picks a random number between 1 and 20.
- You try to guess it by entering numbers.
- After each guess, the game tells you if your guess is too high or too low.
- Once you guess correctly, it shows how many tries it took you.
- The game keeps track of your best record (fewest guesses) across rounds.
- You can choose to play again or stop after each round.

## How to run it

1. Make sure you have Python installed.
2. Download or clone this repository.
3. Run the file:

```bash
python num_guessing_game.py
```
